# 10 Utility Apps

`scripts/generate-portfolio-apps.ps1` creates ten independent XcodeGen iOS projects. Each has its own name, Bundle ID, StoreKit subscription identifiers, local functional workflow, and App Store submission checklist.

Run `xcodegen generate` inside each app folder on a Mac before opening it in Xcode. Configure the corresponding monthly and yearly products, with the introductory offer, in App Store Connect before TestFlight.
