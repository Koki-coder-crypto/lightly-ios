# Photo Cleaner — 機能仕様・提出受入基準

## 製品の約束

Photo Cleaner は、端末内の写真ライブラリから「スクリーンショット」「長いビデオ」「最近の大きい写真」を見直すための iPhone アプリです。写真をアップロードせず、自動削除も行いません。削除は、利用者が選択して確認した項目だけを iOS の「最近削除した項目」へ移動します。

競合アプリの名称、アイコン、文章、固有演出を流用しない。参考にするのは、権限の明示、安全な確認、カテゴリからの素早い見直しという問題解決の原則だけです。

## 機能一覧

| 領域 | 機能 | 完了条件 |
| --- | --- | --- |
| 初回体験 | 端末内処理・非自動削除を説明 | 写真の許可を求める前に読める |
| 権限 | 写真ライブラリの読み書き許可 | 「すべて」「選択した写真」を扱え、拒否後は設定を開ける |
| スキャン | 写真ライブラリを端末内で走査 | スクリーンショット、長い動画、最近の大きい写真を表示し、iCloud 原本を勝手にダウンロードしない |
| 候補一覧 | 件数とカテゴリを表示 | 再スキャンで結果を更新できる |
| メディア確認 | サムネイル、作成日、画像サイズ/動画の長さを表示 | 動画はポスター画像、写真は実データサイズを使う |
| 選択 | 一件ずつ選択・解除 | 無料枠の残数を超える選択は案内を表示する |
| スワイプ確認 | 右で残す、左で削除候補、取り消し | 決定は削除確認まで端末内の一時状態に留める |
| 削除 | 確認後に選択項目を削除 | iOS の「最近削除した項目」へ移動し、失敗時は原因を案内する |
| 無料プラン | 暦月 30 件の削除枠 | 成功した削除だけを消費し、月替わりでリセットする |
| Pro | 月額・年額の自動更新サブスクリプション | 商品表示、購入、復元、現在の権利状態を StoreKit で処理する |
| 課金の透明性 | トライアル・更新・解約・規約を表示 | 商品価格は Apple の表示価格を使い、初回起動で強制しない |
| プライバシー | プライバシーとサポートへの導線 | アカウント、広告、解析、クラウド送信がないことを説明する |
| ローカライズ | 日本語と英語（米国） | 動的なカテゴリ名・画面タイトル・権限文言も英語化される |
| アクセシビリティ | VoiceOver 用の状態・操作名 | 選択状態、更新、主操作を読み上げられる |

## 画面フロー

`ホーム` → `写真へのアクセス` → `カテゴリ一覧` → `一覧で選択` または `スワイプで確認` → `削除確認` → `Photos の最近削除した項目`

Pro は、無料枠の残数を明示したホームまたは上限到達時から任意で開く。購入・復元に失敗しても候補の確認や無料枠は利用できる。

## 提出前の実機受入テスト

1. 新規インストールで、許可前の説明と拒否後の「設定を開く」を確認する。
2. 「選択した写真」だけの許可で各カテゴリを開き、未許可の写真を表示しないことを確認する。
3. スクリーンショット、静止画、動画を含むライブラリでサムネイル・日付・件数を確認する。
4. 1件と複数件を削除し、確認ダイアログの後に Photos の「最近削除した項目」にあることを確認する。
5. スワイプで残す・削除候補・取り消すを確認し、削除をキャンセルした場合は写真と無料枠が変化しないことを確認する。
6. 無料枠 30 件、月替わりのリセット、Sandbox の購入・復元・期限切れを確認する。
7. 日本語と英語（米国）、Dynamic Type 最大、VoiceOverでホーム・一覧・削除・Proを確認する。
8. 6.7インチ iPhone で英語のホーム、候補一覧、削除確認、Pro のスクリーンショットを撮影する。
