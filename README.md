# Caliqo

Private, local-first AR measurement tools for iPhone.

Implemented: AR distance and area measurement, a Core Motion level, screen ruler, room area estimate, and local measurement history with naming, notes, editing, sharing, and deletion. The app has no account, ads, analytics, tracking SDK, or network dependency.

Build on a Mac with Xcode 16+:

1. Install XcodeGen and run `xcodegen generate`.
2. Open `Caliqo.xcodeproj`, select the Apple Developer Team, and run on a real iPhone.
3. Verify camera permission, AR measurement, level, saving/deleting history, Dynamic Type, and VoiceOver before archiving.

AR results can include error. Verify important dimensions with a physical measuring tool.
