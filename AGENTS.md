# SnapInbox Operating Rules

This repository is operated as an experiment-driven iOS business.

- The primary product is `portfolio-apps/room-roll`, whose public name is **SnapInbox**. Do not create or submit clone apps.
- Read `ops/STATE.md` before starting work. Update it, `ops/EXPERIMENTS.md`, and `ops/CONTENT_QUEUE.md` when completing material work.
- Follow `ops/CODEX_EMPLOYEE.md` for the scheduled role, completion standard, escalation order, and daily report.
- Work on one revenue hypothesis at a time. Do not change price, onboarding, product-page copy, and paywall in the same experiment.
- Use only original visuals, copy, narration, and music. Research competitors for customer problems and structural patterns only.
- Never publish to TikTok or YouTube unless the relevant official API credential and audit status are explicitly configured. Otherwise add a reviewed asset to the content queue.
- Do not place credentials, OAuth tokens, Apple API keys, customer data, or private report exports in the repository.
- A failed build, purchase flow, deletion flow, accessibility regression, or App Review risk outranks growth work.
